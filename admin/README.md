# CoinSprite community studio

The dashboard is built from JavaScript components in `layoutKit.js`, `layout.js`, and `pages/`. There are no `.html` source files or exported copies of an older HTML layout. The browser still receives an HTML document, which is generated by these components at request time.

`ui.css` is the only dashboard stylesheet. It provides the warm-grey, ochre, horizontal-navigation design for every tab, profile tool, dialog, and generated editor control. `app.js` and `inventory.js` keep the existing behavior and API bindings; when changing a component, preserve the functional IDs and `data-*` attributes that those scripts use.
